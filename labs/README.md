# Lab README

This folder contains the lab assignments for the Operating Systems course.

## Labs

- `01-linux-processes.md`: observe processes, inspect system services, and explain process states.
- `02-process-creation.md`: understand process creation and process management.
- `03-cpu-scheduling.md`: simulate FCFS, SJF, priority, and round robin scheduling.
- `04-threads.md`: explore threads, race conditions, and synchronization.
- `05-ipc.md`: demonstrate inter-process communication and coordination.

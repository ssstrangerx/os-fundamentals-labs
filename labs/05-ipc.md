# Lab 5: Inter-Process Communication

## Goal

Students will demonstrate cooperation between processes using IPC primitives.

## Tasks

1. Use a pipe to send a message from parent to child.
2. Use a queue to coordinate multiple processes.
3. Discuss how IPC enables process cooperation.
4. Describe the difference between shared memory and message passing.

## Questions

- Why is communication between processes needed?
- What are the benefits of message passing compared with shared memory?
- How does the OS protect process isolation while enabling cooperation?

## Deliverable

Submit a short demonstration and explanation of the IPC mechanism used.

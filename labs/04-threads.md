# Lab 4: Threads and Synchronization

## Goal

Students will understand how threads share memory and how synchronization prevents race conditions.

## Tasks

1. Write a multithreaded Python program that increments a shared variable.
2. Demonstrate the race condition without synchronization.
3. Fix the issue using a lock.
4. Explain why locking is required in shared-memory systems.

## Questions

- What is a race condition?
- How does locking ensure correctness?
- Why are threads useful even though they share memory?

## Deliverable

Provide the code and a short reflection on thread safety.

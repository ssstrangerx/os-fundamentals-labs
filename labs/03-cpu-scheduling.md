# Lab 3: CPU Scheduling Algorithms

## Goal

Students will simulate major CPU scheduling algorithms and compute performance metrics.

## Tasks

1. Implement FCFS scheduling.
2. Implement SJF scheduling.
3. Implement Priority scheduling.
4. Implement Round Robin scheduling.
5. Compare metrics such as waiting time, turnaround time, and response time.

## Required Metrics

- Average waiting time
- Average turnaround time
- Average response time
- Throughput

## Questions

- Which scheduling policy gives the shortest average waiting time?
- What is the trade-off between fairness and efficiency?
- Why does Round Robin sometimes outperform FCFS under interactive loads?

## Deliverable

Provide a table comparing the scheduling algorithms and explain the results.

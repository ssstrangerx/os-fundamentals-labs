# Operating Systems Fundamentals Lab Assignment

## Overview

This lab assignment introduces students to core operating-system concepts using Python and Linux-based programs. Students will observe Linux processes, simulate process scheduling algorithms, analyze performance metrics, explore threads, and demonstrate inter-process communication.

## Objectives

By the end of this assignment, students should be able to:
- explain the purpose of system services and the role of the kernel
- identify process states and inspect running processes using Linux tools
- describe process creation and process lifecycle mechanisms
- compare major CPU scheduling algorithms
- compute and interpret metrics such as waiting time and turnaround time
- explain threads, synchronization, and race conditions
- implement simple IPC using Python multiprocessing primitives

## Deliverables

- A short report (3–5 pages)
- Screenshots or logs from Linux process observation
- Scheduling simulation output and calculations
- Thread synchronization notes and conclusions
- IPC demonstration with explanation of communication flow

## Suggested Schedule

- Week 1: Linux process observation and system services
- Week 2: Process creation and management
- Week 3: CPU scheduling simulation and metrics
- Week 4: Threads and synchronization
- Week 5: IPC and process cooperation

## Required Tools

- Python 3
- Linux environment (Ubuntu or Debian preferred)
- `psutil` Python package
- Terminal and shell tools (`ps`, `top`, `pstree`, `kill`, `sleep`, etc.)

## Assessment Criteria

- Correctness of simulations and examples
- Clarity of analysis and interpretation
- Ability to relate theory to real Linux behavior
- Quality of written explanation and conclusions

1. Run the demo suite using the repository scripts.

4. Include code snippets and screenshots where relevant.
